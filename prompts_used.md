# AI prompts used

The project was created and reviewed with these prompts, adapted from the assessment request:

1. “Create a complete beginner-friendly Library Management System for ABC Engineering College using Python, Streamlit, SQLite, a virtual environment, and Git. Inspect the workspace first. Implement Add Book, View Books, total available copies, most stocked book, and category-wise summary.”
2. “Add robust input validation, initialize the SQLite books schema automatically, and use parameterized SQL queries.”
3. “Add automated tests for adding books, validation, and inventory statistics using an isolated temporary database.”
4. “Write setup/run/test/Git instructions suitable for a student using VS Code on Windows, and ignore the local database and virtual environment in Git.”
5. “Add book editing and safe removal, category filtering, low-stock indicators, and a borrowing/return log that adjusts available copies and preserves loan history.”
6. “Add automated checks for editing/removing books and the borrow/return copy-count changes.”
